## 📖 Tentang Projek

**Astral Qalam Webdev** ialah platform web premium untuk perkhidmatan digital. Projek ini dibina menggunakan **Vue.js 3** dengan **Vite** sebagai build tool, menawarkan pengalaman web yang pantas dan moden.

## ✨ Ciri-ciri Utama

- 🎨 **Single Page Application (SPA)** - Pengalaman pengguna yang lancar tanpa reload
- 🌐 **Multi-language Support** - Boleh ganti antara Bahasa Melayu dan English
- 🌓 **Dark/Light Mode** - Tema yang mudah pada mata
- 💬 **AI Chat Assistant** - Chatbot untuk bantu pelanggan
- 🎯 **Modern UI/UX** - Reka bentuk yang menarik dengan animasi halus
- 🚀 **Fast Performance** - Dibina dengan Vite untuk build yang pantas

## 🛠️ Tech Stack

- **Framework**: Vue.js 3.5+
- **Build Tool**: Vite 6.0
- **Routing**: Vue Router 4.5
- **Styling**: Vue SFC Scoped Styles
- **Icons**: SVG Inline

## 📦 Instalasi

### Syarat Penting

Sebelum mulakan, pastikan anda telah install:

1. **Node.js** (v18 atau lebih tinggi)
2. **npm** atau **yarn**

### Langkah-langkah

```bash
# Clone repository
git clone https://github.com/FDTurbo-3S/astral-qalam-webdev.git

# Masuk ke folder projek
cd astral-qalam-webdev

# Install dependencies
npm install

# Mulakan development server
npm run dev

# Untuk build production
npm run build
```

## 🚀 Skipts Tersedia

```bash
npm run dev      # Development server (http://localhost:5173)
npm run build    # Build untuk production
npm run preview  # Preview build production
```
